# 22. CHKOBBA DEALING

At the beginning:

* 3 cards per player;
* 4 cards face-up in the center.

```text

```

* no additional center cards;

# 23. CHKOBBA CAPTURE RULES

A player must play one card.

### Case 1 — Same value

If a card with the same value exists on the table:

```text
played card + matching card
```

The player MUST capture it.

This has priority over sum capture.

Example:

```text
Player plays 7

Table:
7
3
4

The 7 must capture the 7.
```

---

# 24. CHKOBBA SUM CAPTURE

If no same-value card exists:

The player may capture cards whose total equals the played card.

Example:

```text
Played = 7

Table:
3 + 4
```

Capture:

```text
3 + 4
```

Other example:

```text
7 = 1 + 2 + 4
```

If multiple combinations exist, display legal combinations and allow the player to choose according to the configured Tunisian rule variant.

The server must calculate all valid combinations.

Never trust the client.

---

# 25. NO CAPTURE

If no legal capture exists:

The played card is placed face-up on the table.

---

# 26. MANDATORY CAPTURE

If a legal capture exists:

The player MUST capture.

The UI should highlight legal cards/combinations.

The server must reject illegal moves.

---

# 27. CHKOBBA

If a capture removes every card from the table:

```text
+1 CHKOBBA
```

The capturing card is marked appropriately.

IMPORTANT:

If the table is emptied by the very last played card of the round:

```text
NO CHKOBBA POINT
```

At the end of the round:

Remaining table cards go to the last player/team who captured.

No Chkobba point is awarded for those cards.
